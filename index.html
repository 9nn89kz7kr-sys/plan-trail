    Activités Garmin

    1. Sur connect.garmin.com, ouvre Activités, puis Toutes les activités.
    2. Fais défiler jusqu’en bas pour charger les semaines voulues, puis clique sur Exporter CSV.
    3. Choisis le fichier ci-dessous : les km, le D+, le D- et les heures réalisés se calculent pour chaque semaine du plan.

    Séances depuis Excel

    Importe un CSV au format du modèle pour ajouter des séances ou mettre à jour celles qui ont le même identifiant.

    Agenda

    Télécharge toutes les séances au format calendrier. Dans Apple Calendar, importe-le dans un calendrier dédié « Plan trail » ; pour mettre à jour, supprime ce calendrier et réimporte.

    Réglages du programme

    Le lundi de la semaine 1. Toutes les semaines du programme sont numérotées à partir de cette date.

    Sauvegarde

    Le fichier de sauvegarde contient tout : plan, réalisé, bilans et objectifs. C’est aussi celui à envoyer à Claude pour faire le point.
